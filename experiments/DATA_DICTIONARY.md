# Snapse Research Data Dictionary

This document defines the schema, units, collection methods, and semantic definitions of all telemetry fields captured during the empirical evaluation of the Snapse desktop monitoring engine.

---

## 1. Raw Telemetry Logs (`experiments/raw/telemetry_*.csv`)

Each record represents one discrete interrogation tick performed by the monitoring engine on the Windows NT host.

| Column Name | Data Type | Units / Format | Description |
| :--- | :--- | :--- | :--- |
| `timestamp_ms` | `int64` | Milliseconds (UTC Epoch) | High-resolution timestamp from `chrono::Utc::now().timestamp_millis()`. |
| `mode` | `string` | Categorical | Active sampling configuration (`Fixed_250ms`, `Fixed_500ms`, `Fixed_1000ms`, `Fixed_2000ms`, `Adaptive_VAC`). |
| `target_interval_ms` | `uint64` | Milliseconds | The target sleep interval commanded by the sampling controller. |
| `actual_interval_ms` | `float64` | Milliseconds | The actual measured wall-clock duration elapsed between the previous tick and the current tick. |
| `jitter_ms` | `float64` | Milliseconds | Absolute timer error: $\|T_{\text{actual}} - T_{\text{target}}\|$. |
| `collection_duration_us` | `uint64` | Microseconds ($\mu\text{s}$) | CPU time spent executing kernel queries (`NtQuerySystemInformation`, process traversal, memory calculations). |
| `observer_cpu_percent` | `float32` | Percentage ($0.0 - 100.0\%$) | CPU utilization consumed exclusively by the Snapse monitoring process (`sysinfo::Process::cpu_usage`). |
| `observer_memory_bytes` | `uint64` | Bytes | Private resident memory / working set of the Snapse monitoring process. |
| `state` | `string` | Categorical | Internal FSM state of the Volatility-Aware Controller (`IDLE`, `NORMAL`, `ACTIVE`, or `FIXED_*`). |
| `volatility_score` | `float32` | Score ($0.0 - 100.0$) | Instantaneous weighted velocity across CPU, memory, and process delta. |
| `smoothed_volatility` | `float32` | Score ($0.0 - 100.0$) | Exponential moving average ($\bar{V}$) calculated with smoothing factor $\alpha = 0.40$. |
| `system_cpu_percent` | `float32` | Percentage ($0.0 - 100.0\%$) | System-wide global CPU utilization across all logical processors. |
| `system_memory_percent` | `float32` | Percentage ($0.0 - 100.0\%$) | System-wide physical RAM utilization percentage. |
| `process_count` | `uint32` | Count | Total number of active operating system processes enumerated in the snapshot. |

## 2. Experiment Run Manifest (`experiments/manifests/experiment_manifest.csv`)

Summarizes execution parameters and aggregate performance statistics for each trial.

| Column Name | Data Type | Units / Format | Description |
| :--- | :--- | :--- | :--- |
| `RunID` | `string` | Unique identifier | Format: `{Mode}_{Workload}_{Repetition}`. |
| `Mode` | `string` | Categorical | Experimental sampling mode under test. |
| `Repetition` | `int` | Integer ($1 - N$) | Trial repetition index. |
| `Workload` | `string` | Categorical | Workload stimulus: `Idle_Baseline` or `Churn_Bursts`. |
| `DurationSec` | `uint64` | Seconds | Planned active recording duration. |
| `SamplesCount` | `int` | Count | Total number of telemetry samples successfully gathered. |
| `MeanActualIntervalMs` | `float64` | Milliseconds | Arithmetic mean of observed sampling intervals. |
| `MeanJitterMs` | `float64` | Milliseconds | Arithmetic mean of timer jitter across the trial. |
| `MeanObserverCpuPct` | `float32` | Percentage | Mean CPU utilization consumed by the monitor. |
| `MeanObserverMemMB` | `float64` | Megabytes (MB) | Mean private memory footprint of the monitor. |
| `MeanCollectionUs` | `float64` | Microseconds | Mean execution time for kernel data collection. |
| `TelemetryFile` | `string` | File path | Absolute or relative path to the full raw CSV log. |

---

## 3. Workload Ground-Truth Manifest (`experiments/manifests/workload_groundtruth.csv`)

Records precise synthetic stimulus injection boundaries generated by benchmark scripts.

| Column Name | Data Type | Units / Format | Description |
| :--- | :--- | :--- | :--- |
| `Workload` | `string` | Categorical | Name of synthetic generator (`CPU_Burst`, `Memory_Ramp`, `Disk_IO`). |
| `DurationSec` | `int` | Seconds | Target injection duration. |
| `Threads` / `SizeMB` | `int` | Integer | Workload scale parameter (thread count or allocated megabytes). |
| `StartTimestampMs` | `int64` | Milliseconds (UTC) | Exact millisecond timestamp at which workload worker threads launched. |
| `EndTimestampMs` | `int64` | Milliseconds (UTC) | Exact millisecond timestamp at which workload worker threads terminated and resources freed. |
| `IsoStart` | `string` | ISO 8601 UTC | Human-readable start timestamp. |
| `IsoEnd` | `string` | ISO 8601 UTC | Human-readable completion timestamp. |
